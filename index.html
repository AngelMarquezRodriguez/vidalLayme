Integración numérica

Calcula integrales definidas con trapecio compuesto, Simpson 1/3 y Simpson 3/8, a partir de datos tabulados o de una función f(x).

Datos de entrada

Sepárelos con espacios, saltos de línea, punto y coma o comas. La coma dentro de un número (0,5) se lee como decimal.

Use * para multiplicar y ^ para potencias. Funciones: sin, cos, tan, sinh, cosh, exp, ln, log, sqrt, abs; constantes pi y e.

Método

Unidades y referencia

Sin valor de referencia no se puede calcular el error verdadero. Se compara con el resultado ya convertido.

Resultados

Ingrese los datos y presione Calcular.
